# Cadence REPL

A simple REPL for evaluating [Cadence](https://github.com/connordoman/cadence) expressions.

## Run the REPL

```sh
go run github.com/connordoman/cadence@latest
```

### Flags

- `-r`, `--human-readable`: output dates in a more scannable format with ISO week numbers, days of the week, and months as text.
- `-v`, `--verbose`: output more detailed results
